# Suraj & Jyoti — Wedding Invitation

An animated wedding invitation: velvet doors open onto an arched card that steps through the monogram, the invitation, Haldi, Mehendi and the Wedding.

**Live:** https://surajdahman11-pro.github.io/SurajJyotiWedding/

## Editing the wording

Open `index.html` and search for `EDIT YOUR DETAILS HERE`. Every name, date, time and venue sits in that one block. Change only the text inside the quotes, then commit. The live page updates within a minute or two.

## Files

- `index.html`: the whole invitation (artwork, animation and text) in one file
- `preview.jpg`: the image WhatsApp and other apps show when the link is shared
